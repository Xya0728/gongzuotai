# Xya 的工作台

一个只跑在自己电脑上的个人工作台：把每天的计划、跨境工作、学习、健身、饮食、设备、消费放在一个页面里。

没有账号、没有云端、没有手机号注册。数据默认保存在本机的 `data/工作台数据.json`，也可以直接在浏览器里用 `localStorage` 运行。

## 功能

| 模块 | 内容 |
|---|---|
| **首页总览** | 简约时钟、汕头天气、学习/训练/热量/支出概览、模块摘要、快速备忘 |
| **今日计划** | 时间轴与清单两种视图；拖色块改时间；长按空白时间加计划；学习/健身/饮食/工作/娱乐模块可直接拖进日程；计划偏好可改作息、用餐时段和固定安排 |
| **跨境工作** | 店铺、订单、库存补货提醒、选品看板、广告记录 |
| **学习计划** | 学习项目分类（书籍 / 乐器 / 课程，可自定义）、封面图片、截止日期、备注 |
| **健身计划** | 按周排训练；推日 / 拉日 / 腿日模板，动作与组数；可拖拽的「休息日」；体重围度趋势 |
| **饮食计划** | 一日餐饮搭配；热量 / 蛋白质进度；食物热量按分量和做法估算（去皮、少糖等）；身高体重与 BMI；饮水、咖啡 |
| **游戏娱乐** | 我的设备：键盘 / 鼠标 / 耳机 |
| **消费记录** | 账单、预算圆环、资产管家、周/月/年支出分析与排行榜、明细记账 |
| **数据与设置** | 数据文件、备份恢复、汇率、饮水偏好、模块显示、立即保存 |

不做打卡：计划只负责把事情排好，学习 / 健身 / 饮食不记录连续天数或完成率；消费记账保留。

## 技术栈

- **前端**：原生 HTML / CSS / JavaScript，无构建步骤，直接 `<script>` 加载
- **路由**：hash 路由（`#/home`、`#/plan` …），页面注册在 `Pages`
- **后端**：Python 3 标准库 HTTP 服务，负责静态文件和 `GET/PUT /api/state`
- **存储**：优先写 `data/工作台数据.json`；直接打开 `index.html` 时退回 `localStorage`
- **手机**：PWA（manifest + Service Worker + 底部导航），可添加到 iPhone 主屏幕
- **测试**：Headless Chrome 运行 `tests/run.sh`，覆盖桌面、数据服务、390px 手机布局和 PWA 资源

## 快速开始

### macOS

双击：

```text
启动Xya的工作台.command
```

### Windows

双击：

```text
启动Xya的工作台.bat
```

### 命令行

```bash
python3 server.py
```

然后打开 <http://127.0.0.1:8765>。

数据文件：

```text
data/工作台数据.json
```

### 直接打开网页

双击 `index.html` 也能用，但数据只存在浏览器 `localStorage` 里，清理网站数据会丢，不建议长期使用。

## 手机上使用

- **同一 Wi-Fi（不需要装手机 App）**：双击 `启动手机访问（同一Wi-Fi）.command`，iPhone Safari 打开终端打印的局域网地址，分享 → 添加到主屏幕。
- **外网（Tailscale）**：Mac / iPhone 安装 Tailscale 并登录同一账号，双击 `启动手机访问.command`，用打印的 `https://…ts.net` 地址添加到主屏幕。

详细步骤、数据同步和限制见 [手机访问说明.txt](手机访问说明.txt)。

## 测试

```bash
bash tests/run.sh
```

会依次执行：

1. 文件模式（`file://` + `localStorage`）
2. 数据文件模式（本地 HTTP 服务 + JSON 文件）
3. 手机布局（390 × 844）
4. 数据服务 / PWA 检查（manifest、Service Worker、图标、UTF-8、缓存头）

## 数据与隐私

- `data/`、`验收截图/`、`.DS_Store` 已在 `.gitignore`，不会进入 Git。
- 数据默认只在本机；没有登录、没有云同步。
- 天气使用 Open-Meteo 免费接口，是应用里唯一的联网请求；天气不可用时显示缓存或离线提示。
- 如果通过 Tailscale 在手机访问，流量只在自己的 tailnet 内；不要使用 `tailscale funnel` 把服务公开到公网。
- 备份：`数据与设置 → 导出备份`，会下载一个 JSON 文件。
